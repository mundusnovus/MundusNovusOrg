Opening them the first time

  • macOS. Open the disk image and drag the app to Applications. The first time, right-click the app and choose Open, because it is not yet notarized by Apple.
  • Windows. Unzip the folder and double-click the .cmd file. The app opens in Microsoft Edge as its own window.
  • Linux. Install the .deb with your software installer, or unpack the .tar.gz and run the launcher inside. It opens as its own window in Chromium, Chrome, Edge or Brave.

Every file has a SHA-256 checksum, so you can check that it arrived unchanged.
