Asteria Cloud and Asteria Office

The desktop apps for Cloud (keeps a folder on your computer in sync) and Office (edit documents offline) are built for Windows, macOS and Linux with every release.

Every file

Each file has a SHA-256 checksum, so you can check it arrived unchanged.

Opening these desktop downloads

  • macOS. Open the disk image and drag the app to Applications. The first time, right-click the app and choose Open, because it is not yet notarized by Apple.
  • Windows. Unzip the folder and double-click the .cmd file. The app opens in Microsoft Edge as its own window.
  • Linux. Install the .deb with your software installer, or unpack the .tar.gz and run the launcher inside.
  • Phones and tablets. Open Sprite or Box in your browser and add it to your home screen.
