Asteria Search

Not a search engine. A library with opinions, and a strong preference for not being lied to by ads.

Asteria Search is the proprietary Swift package that powers search in Asteria Browse. It asks public sources directly from the device, merges what they return, removes ad networks and tracking parameters, and lets Asteria Intelligence judge the top results. There is no Asteria search index, no Asteria account, no API key, and no server in the middle pretending to be neutral.

How it works

Ask the sources

Web search asks Bing, DuckDuckGo, Wikipedia in the region’s language, and Bing News. Images ask Bing Images and Wikimedia Commons. Videos ask Bing Videos. Brave is available but off by default; Google is never scraped. You can choose Google as your browser engine if you prefer, which is a different sentence.

Merge, then filter

Reciprocal rank fusion merges the lists. Every link passes a public HTTP(S) check and then an ad-network and paid-campaign filter. Tracking keys are removed. Result types are classified from the address and byline, so a forum post does not get to masquerade as a reference work.

Let the model sort

The top twelve web results are judged by Asteria Intelligence, through FoundationModels: useful, advertising, spam, off topic, and a relevance from 0 to 10. Snippets are untrusted input. A reference work is never removed, and at most a third of the judged results can be. If the model skips most of them, the fused order stands.

Write the overview

Two to four sentences with numbered sources, streamed as it is written. It reads snippets, not full pages, so it can be wrong. That is why the sources are beside it and why the page does not pretend otherwise.

Fail one source, not the search

A human check, a rate limit, or a page that stops parsing fails that source only. The host rests for five minutes. The library never solves challenges, poses as another browser, rotates proxies, or retries. We have limits. They are features.

Asteria Intelligence, asked first

Ranking and the overview use Asteria Intelligence only after the person turns it on. Asteria’s gateway passes each request to the model and keeps none of it. Off, the fused order stands and nothing is sent.

The privacy bit

The transport is an ephemeral URLSession with no cookies and no cache. The app sends one identifying User-Agent and your preferred languages. Queries, IP addresses and request metadata still reach each source that is asked; asking from your device does not make search anonymous. There is no query history, analytics or caching in the library. With Asteria Intelligence on, the query and the top snippets also go to it for ranking and the overview. A region sends a country, a language and optionally a city; the city is used only to rewrite “near me” for web sources, and Wikipedia never receives it.

No SearXNG, AltStackSearch or other copyleft implementation was copied or linked. The library is proprietary Swift, built by Asteria Technology, and it lives inside Asteria Browse.
