Draw, animate and export pixel art. Describe a sprite and the assistant draws it with you, one step you can undo at a time.

What it does

Layers and frames

Blend modes, onion skin, tags and playback. Indexed or full colour.

Brushes that shade

Pixel-perfect pencil, shading and dither brushes, gradients, mirror and tiled drawing.

Clean transforms

Outline, drop shadow, light-direction shading, and rotation that keeps pixels crisp.

Palettes

Build ramps, import GPL, hex, JASC or PNG, or start from a classic.

Ready for games

Sprite sheets with Aseprite-compatible JSON and Godot resources, plus PNG, GIF and APNG.

An assistant at your side

It works with your own Anthropic key, kept on your device, and every step can be undone. Or ask your own agent.

Work with your agent

Ask your agent

MNSprite comes with instructions for AI agents. An agent that can run code can use the same tools as the editor's own assistant, and hand you a file you can open here and keep working on.

  1. Claude. In the Claude desktop app, open Cowork, give it a folder to work in, and paste the prompt.
  2. ChatGPT. Start a task in agent mode, or in Codex, and paste the prompt.
  3. Change the last sentence to say what you want. Then open the file it gives you in the editor.
