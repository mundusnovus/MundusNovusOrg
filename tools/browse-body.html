Asteria Browse

A browser that minds its own business. Search that does the reading first.

Asteria Browse is a native WebKit browser with Spaces, favorites, pinned tabs and a sidebar that does not need a tour. The search bar runs Asteria Search: the device asks Bing, DuckDuckGo, Wikipedia, news, images and video sources directly, merges what comes back, removes the ads and trackers, and lets Apple Intelligence put the useful results first.

What it does

Asteria Search 2.0

All, Websites, Articles, Images and Videos. Bing, DuckDuckGo, Wikipedia, Bing News, Bing Images, Wikimedia Commons and Bing Videos, merged with reciprocal rank fusion. Brave is available but off by default. Google is never scraped; choose it as your engine if you want it.

Apple Intelligence, on device

The top results are judged for usefulness, ads, spam and relevance by the on-device model. Ads and spam sink or disappear; a reference work is never removed. A short overview is written with numbered sources, because a citation is cheaper than an apology.

Drag it where it goes

Drag a tab into Favorites, Pinned, a bookmark folder or another Space. Drag a search result into the sidebar to save it. Empty sections show where to drop. Every drag also has a menu and a VoiceOver action, because accessibility is not a nice-to-have.

Private tabs

Each private tab gets its own temporary website data, no history, no searches, no downloads list. It does not hide your traffic from the network. It does keep the tab out of everything else, which is the part you asked for.

Siri and Spotlight

Ask Siri to search, rerun a past search, open a bookmark or open a private tab. History, searches and bookmarks can appear in Spotlight. Private tabs never do. Settings has one switch for the whole lot.

Everything else

Find on page, zoom, print and PDF, downloads with resume, website data controls, permission prompts, external links, and a search engine picker that includes Google, Startpage, Kagi, DuckDuckGo, Bing and Brave. Safari tabs, bookmarks and extensions are not synced or loaded.

Asteria Search is not a search engine

It is a library with opinions. It does not crawl the web, run an index, or pretend to know everything. It asks public sources, merges the results, removes ad networks and tracking parameters, and lets Apple Intelligence re-rank the top twelve. The overview is generated from snippets, so a claim or a citation can be wrong; the sources are shown beside it for that reason. There is no Asteria search server, no account and no API key.

Our promise
